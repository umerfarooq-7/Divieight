# Query plans (EXPLAIN)

Generated by `tests/hardening-db.test.ts` on the database built from the repository's own SQL, with sequential scans disabled so the planner shows which index it would use. The tables are empty, so the plans show access paths, not timings: real row counts and timings need a copy of production data (see docs/performance.md).
